# Every active employee has completed security-awareness training in the last 12 months

`ISO27001-A.6.3-awareness-training` · framework **iso27001** · severity **high** · People Controls

## What this control checks

ISO/IEC 27001:2022 A.6.3 requires personnel to receive appropriate
information-security awareness training. Concord reads the
Concord training_completion table (Φ-9 schema) and verifies every
active person has a completion in the last 365 days.

## Why it matters

Lapsed training is one of the cheapest A.6 audit findings.
Tracking via Concord's own training_completion store keeps this
test in the same system that auditors already have access to.

## Evidence

Collected from the `attestation` source (`policy_attestation` evidence type).

## What a failure looks like

This control reports a finding when any of the following hold:

- no training-register attestation collected
- attestation kind is <value>, expected "training_register"
- training-register attestation cosign signature did not verify
- active employee <value> has no security-awareness completion in the last <value> days

## Remediation

Bring each affected resource or attestation listed under *What a failure looks like* into compliance, then re-collect evidence. Estimated effort: **2w**. Automated fix available: **false**.

## How to re-verify

```
concord check --controls <pack>/controls --framework iso27001 --control-id ISO27001-A.6.3-awareness-training
```

A passing run reports this control green; in CI, `concord gate` exits non-zero while it fails.
