# Networks, systems, and applications are monitored continuously (CloudTrail multi-region + management events)

`ISO27001-A.8.16-monitoring-activities` · framework **iso27001** · severity **critical** · Technological Controls

## What this control checks

ISO/IEC 27001:2022 A.8.16 requires continuous monitoring of
networks, systems, and applications for anomalous behaviour.
Concord verifies CloudTrail covers every region with management
events enabled.

## Why it matters

Single-region CloudTrail is a common audit gap — it provides
visibility into one region's API plane only. A.8.16 expects
end-to-end account coverage.

## Evidence

Collected from the `aws` source (`cloudtrail_trails` evidence type).

## What a failure looks like

This control reports a finding when any of the following hold:

- no CloudTrail evidence collected
- no multi-region CloudTrail trail is logging — A.8.16 requires monitoring coverage across every region
- trail <value> does not record management events

## Remediation

Bring each affected resource or attestation listed under *What a failure looks like* into compliance, then re-collect evidence. Estimated effort: **30m**. Automated fix available: **true**.
