# Documented operating procedures exist for security-relevant operations

`ISO27001-A.5.37-documented-procedures` · framework **iso27001** · severity **medium** · Organisational Controls

## What this control checks

ISO/IEC 27001:2022 A.5.37 requires operating procedures for IT
operations to be documented and made available. Concord reads a
cosigned attestation of the runbook catalogue.

## Why it matters

Catalogue completeness — every documented attack surface has a
runbook — is what A.5.37 audits land on.

## Evidence

Collected from the `attestation` source (`policy_attestation` evidence type).

## What a failure looks like

This control reports a finding when any of the following hold:

- no runbook-catalogue attestation collected
- runbook-catalogue attestation cosign signature did not verify
- required runbook <value> is missing from the catalogue
- runbook <value> last reviewed <value> days ago

## Remediation

Bring each affected resource or attestation listed under *What a failure looks like* into compliance, then re-collect evidence. Estimated effort: **1w**. Automated fix available: **false**.

## How to re-verify

```
concord check --controls <pack>/controls --framework iso27001 --control-id ISO27001-A.5.37-documented-procedures
```

A passing run reports this control green; in CI, `concord gate` exits non-zero while it fails.
